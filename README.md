# subscription-pricing-ui

High-fidelity desktop subscription pricing prototype.

## Scope

This stage implements the approved static initial Free-plan pricing page. It follows the project HF brief, approved UI_COPY_V2 copy, R2-WF-05 composition baseline, and Tesla-derived visual language.

No real payment flow, backend subscription API, refund flow, downgrade flow, or unapproved product functionality is included.

## Local preview

Open `index.html` directly or serve the repository root with any static web server.
